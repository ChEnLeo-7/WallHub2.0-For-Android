# WallHub MPKG 档位 UI 预览

这是独立于 Android 生产源码的静态交互原型，用于在实现前确认本地 MPKG 列表、详情页和转换档位证据展示。

## 启动

```bash
python3 -m http.server 4180 --bind 0.0.0.0
```

在本仓库根目录执行时需要先进入：

```bash
cd prototypes/mpkg-tier-preview
```

当前局域网预览地址：

```text
http://192.168.2.155:4180/
```

## 交互

- 点击任意 MPKG 进入详情。
- 右下角“滑杆”按钮比较四种识别状态：
  - 文件声明（精确）
  - 内容推断
  - 无法完全确认
  - 外部文件未知
- 月亮按钮切换明暗主题。
- 手机宽度使用底部导航；宽屏/横屏使用 240px 侧边导航。

原型不读取真实 MPKG，也不会改动 Android 应用数据。
